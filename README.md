# 💻 Landing Page — PD Case

## 🚀 Sobre o Projeto

Este projeto consiste em uma landing page de apresentação da PD Case, criada como exercício prático de desenvolvimento web. A página reúne uma apresentação inicial, informações sobre a empresa, um serviço e um depoimento de cliente.

## ✨ Seções e recursos

- **Cabeçalho:** exibe a identificação da empresa e uma barra de navegação.
- **Apresentação:** inclui uma mensagem de boas-vindas e o botão “Saiba mais”.
- **Sobre nós:** apresenta uma breve descrição da empresa.
- **Serviços:** destaca a criação de sites modernos e responsivos.
- **Depoimentos:** mostra uma avaliação de cliente.
- **Interação:** ao clicar no botão da apresentação, é exibida uma mensagem de alerta.

## 🛠️ Tecnologias Utilizadas

- **HTML5:** estruturação do conteúdo e das seções da página.
- **CSS3:** estilos, cores, tipografia e organização dos elementos.
- **JavaScript:** comportamento do botão “Saiba mais”.

O projeto não utiliza frameworks nem dependências externas.

## 📁 Estrutura do Projeto

```text
landing-page/
├── index.html
├── style.css
├── function.js
└── README.md
```

- `index.html`: estrutura e conteúdo da landing page.
- `style.css`: estilos visuais da página.
- `function.js`: interação do botão de apresentação.
- `README.md`: documentação do projeto.

## ⚙️ Como Executar o Projeto

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto em um editor de código, como o Visual Studio Code.
3. Abra o arquivo `index.html` diretamente no navegador ou utilize uma extensão como Live Server.

Não é necessário instalar dependências ou configurar um servidor back-end.

## 🎯 Objetivo de Aprendizado

Praticar a criação de uma página de apresentação com HTML, CSS e JavaScript, organizando conteúdo em seções e adicionando uma interação simples.
